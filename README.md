# Grinder

A RuneLite plugin for tracking your Old School RuneScape goals.

## Features

- Track skill levels and experience, combat and total levels, and base levels across all skills.
- Follow quests, achievement diaries, combat achievements, collection-log unlocks, activity counters, Slayer points and task streaks.
- Set item-quantity goals using known inventory, equipment, bank and supported storage contents.
- Create custom goals, checklists, linked goals, and daily, weekly or monthly routines.
- Search, filter, categorize and pin goals; edit targets and view completion history.
- Choose completion popups, local chat messages and optional desktop notifications.
- Export and import local backups of your account's goals.

## Getting started

Open Grinder from the RuneLite sidebar and select **Add goal**. Use a goal's actions menu to edit or delete it. The header menu contains defaults, presets, bulk management, backups and **Clear all goals**.

Adjust appearance and notification preferences in **RuneLite settings → Grinder**. Example goals are hidden by default; enable them in Display settings to try the available trackers.

## Progress and privacy

Progress uses information available to your logged-in client. Some readings require opening the relevant game interface. Item quantities cover known storage, not every possible location, and collection-log dates record when Grinder first observed an unlock.

Personal routines reset at UTC day, week or month boundaries. Offline progress across a reset may not be attributable to the correct period.

Profiles and backups are local. Grinder does not automate gameplay or send chat messages to other players.
